# Hello, World! - Bubbletea TUI

A fun "Hello, World!" application built with Go and the [Bubbletea](https://github.com/charmbracelet/bubbletea) TUI framework.

## Features

- Animated rotating greeting
- Spinner animation
- Rainbow gradient visual effects
- Colorful styling with lipgloss
- Press `q` to quit

## Requirements

- Go 1.21 or higher

## Running

```bash
go run main.go
```

## Building

```bash
go build -o hello-bubbletea
./hello-bubbletea
```
